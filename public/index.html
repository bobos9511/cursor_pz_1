기본(Default) 시스템 프롬프트

                            

                            
                            
                            

                                

                                    
                                    
                                    
                                

                                
Temperature가 높을수록 답변이 다양해지고, 낮을수록 일관성이 높아집니다.

                                POST
                                
AI 답변 (게시물)

                                
                            

                            
게시판 유형별로 시스템 프롬프트와 Temperature·Top-P를 지정합니다.

                            

                                
                                
                            

                            

                                

                                    

                                        
기본(Default) — IT

                                        

                                    

                                    
                                    
                                    

                                        

                                            
                                            
                                            
                                        

                                        
Temperature가 높을수록 문장 다양성이 올라가고, 낮을수록 사실 중심의 답변이 안정적입니다.

                                        

                                            
                                            
                                            
                                        

                                        
Top-P는 답변 후보 폭을 조절합니다. 낮추면 보수적, 높이면 표현 범위가 넓어집니다.

                                    

                                

                                

                                    

                                        
기본(Default) — BIZ

                                        

                                    

                                    
                                    
                                    

                                        

                                            
                                            
                                            
                                        

                                        
Temperature가 높으면 설명형 문장이 자연스러워지고, 낮으면 규정형 답변의 일관성이 높아집니다.

                                        

                                            
                                            
                                            
                                        

                                        
Top-P는 단어 선택 폭 제어값입니다. 규정/상품 안내는 0.8~0.95 범위에서 시작하는 것을 권장합니다.

                                    

                                

                                
                            

                        


                        

                            

                                RUNTIME
                                
토큰/이어쓰기 설정

                                
                            

                            
AI채팅과 AI답변(게시물)을 각각 설정할 수 있습니다. 입력이 비어 있으면 기본값 수치를 자동 적용합니다.

                            

                                
AI채팅

                                

                                    
                                    
                                    기본값: -
                                

                                
한 번의 채팅 응답 길이 제한입니다. 낮으면 답변이 중간에 끊길 수 있습니다.

                                

                                    
                                    
                                    기본값: -
                                

                                
응답이 잘릴 때 자동으로 이어쓰기하는 최대 횟수입니다.

                                

                                    
                                    
                                    기본값: -
                                

                                
이어쓰기 전체 동작 시간 제한입니다. 초과 시 안전하게 종료됩니다.

                                
AI답변 (게시물)

                                

                                    
                                    
                                    기본값: -
                                

                                
게시판 답변(IT/규정) 1회 생성 길이 제한입니다.

                                

                                    
                                    
                                    기본값: -
                                

                                
게시물 답변이 길어 잘렸을 때 자동 이어쓰기 최대 횟수입니다.

                                

                                    
                                    
                                    기본값: -
                                

                                
게시물 이어쓰기 전체 동작 시간 제한입니다.
